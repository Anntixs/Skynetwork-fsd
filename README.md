# SkyNetwork

Сеть виртуальной авиации по типу VATSIM.

## 1. Серверная часть (ядро сети)

Всё ядро написано на **C++17** и собирается через CMake. Нужны только OpenSSL и SQLite.

### FSD — `skynet-fsd` (Flight Simulator Daemon)

Главный сервер сети. Он принимает координаты самолётов, передаёт данные между пользователями и координирует сеть. Работает по классическому текстовому **протоколу FSD**, который открыл Marty Bochane: `#AP`, `#AA`, `@`, `%`, `#TM`, `$FP`, `$CQ`/`$CR`, `$PI`/`$PO`, `$ER`…

- TCP-порт `6809`: один поток, неблокирующий ввод-вывод через `poll()`
- Авторизация по CID и паролю (PBKDF2-SHA256 в SQLite), рейтинги OBS…ADM, блокировка аккаунтов
- Пилоты и диспетчеры. Позиции рассылаются только тем, кто в зоне видимости: у пилотов 60 nm, у диспетчеров — их радиус, но не больше 600 nm
- Флайт-планы: подача (`$FP`), запрос у сервера (`$CQ…:SERVER:FP:<cs>`), правка диспетчером (`$AM`)
- Сообщения: личные, на частоту (`@18100`), супервизорам (`*S`), общая рассылка (`*`, только SUP и ADM)
- Защита от подмены позывного, тайм-ауты, ограничения на длину строки и размер буфера
- Публичный JSON-фид онлайна: `http://host:8080/data.json`

### Голосовой движок — `skynet-voice` (по схеме Audio for VATSIM)

UDP-сервер радиосвязи, порт `3782`. Сервер **не декодирует звук**. Клиент сообщает свои трансиверы (частота, координаты, высота антенны) и отправляет кадры **Opus** с отметкой, на каких трансиверах идёт передача. Сервер пересылает кадр только тем, у кого есть трансивер на той же частоте в пределах прямой видимости УКВ: `1.23·(√h1 + √h2)` nm. К кадру он добавляет **силу сигнала** от 0 до 1. По ней клиент (будущий аналог TrackAudio, vPilot, xPilot) накладывает затухание, шум и полосовой фильтр УКВ-радио. Формат пакетов описан в `server/voice/voice_server.h`.

### Администрирование — `skynet-admin`

```bash
skynet-admin --db skynetwork.db adduser 1000001 "Ivan Petrov" secret S2
skynet-admin rating 1000001 C1
skynet-admin passwd 1000001 newpass
skynet-admin suspend 1000001
```

## Сборка и запуск

```bash
sudo apt install cmake g++ libssl-dev libsqlite3-dev
cmake -S server -B build && cmake --build build -j
./build/skynet-fsd   --db skynetwork.db --port 6809 --http-port 8080
./build/skynet-voice --db skynetwork.db --port 3782
```

## Тесты

Интеграционные тесты запускают настоящие бинарники:
